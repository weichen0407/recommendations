口径说明

数据日期
2026-09-09 和 2026-09-10。
数据集
eureka产品行为数据 - 2025年1月及以后-关联付费属性。
PV
按过滤后的事件行数计算：source_type=plg_show_rc 为展开，source_type=plg_click_rc 为触发对话。
有效 UV
优先使用非空且非 0000000000000000 的 user_id，其次使用 btu_id，再用 event_detail.session_id 或 raw_session_id。如果仍缺失，只能落到 resolved_session_id 的行级兜底。
UV 风险
2026-09-10 的 plg_show_rc 有 16 条游客行没有 btu_id 和真实 session，行级兜底会让有效 UV 偏高；2026-09-09 没有游客行。
真激活口径
用点击明细里的 session_id 匹配真激活表 resolved_session_id，且 is_true_activation_session=1 计为真激活。未传 session_id 的点击记为无法判定。
query 来源
query 来自真激活/会话主表的 full_query_with_round。只有精确匹配到 resolved_session_id 的推荐点击会话展示 query；未命中会话主表的不反查其他用户会话。
本地文件
明细导出保存在 plg_show_rc_2026-09-09.json、plg_click_rc_2026-09-09.json、plg_show_rc_2026-09-10.json、plg_click_rc_2026-09-10.json、recommendation_true_activation_matched_sessions_with_query.json。
